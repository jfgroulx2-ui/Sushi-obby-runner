# Sushi-obby Mayhem

*All you can eat until defeat.*

A kids' 2D endless obstacle-course game set in neon-lit night-time Tokyo. One file, no build step.

## Deploy on Netlify
1. Drag this folder onto https://app.netlify.com/drop, **or**
2. Push it to a Git repo and connect the repo in Netlify (publish directory: `.`).

## Play
- Keyboard: Space / ↑ / W = jump (press twice for a double jump), ↓ / S = duck.
- Touch: two big buttons at the bottom (Duck left, Jump right). Landscape only on phones.

## Rules
- Pick Chubby Ninja or Wasabi Tiger.
- Jump over sushi blocks and tempura pots. Duck under seaweed walls.
- Knives drop from the ceiling with a "!" warning — jump over them once they land.
- Angry chefs run at you waving a cleaver — jump over them, or land on their hat Mario-style for +3 bottles.
- Ramen slides launch you into the air for bonus soy sauce bottles.
- Soy sauce bottles = points. 3 hearts; lose them all and the run ends. Best score is saved on the device.
